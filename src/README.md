# Compiler and execution projects

Projects here parse and type-check Plato, interpret typed programs, execute compiled laws, expose navigation queries, and provide CLI entry points. Begin with [the compiler](Plato.Compiler/README.md), [interpreter](Plato.Interpreter/README.md), [navigation](Plato.Navigation/README.md), or [CLI](Plato.CLI/README.md). Language emitters live in [writers](../writers/README.md); the handwritten generated-code runtime is [Plato.Intrinsics](Plato.Intrinsics/README.md).
