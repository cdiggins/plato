# Indexing

This folder holds the code for building and querying immutable source navigation indexes. The namespace remains the project namespace; these folders separate responsibilities without introducing assembly boundaries.

Start with `IncrementalIndexer.cs`, `NavigationBuilder.cs`, `NavigationIndex.cs`, `NavigationJson.cs`, `ParseCache.cs`, `PlatoBinder.cs`, `Records.cs`, `ReferenceExtractor.cs`, `SourceSnapshot.cs`. See the [project guide](../README.md) for usage, contracts and verification.
