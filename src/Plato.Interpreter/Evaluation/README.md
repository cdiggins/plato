# Evaluation

This folder holds the code for evaluating typed expressions and representing runtime values. The namespace remains the project namespace; these folders separate responsibilities without introducing assembly boundaries.

Start with `CallMemo.cs`, `CallProfile.cs`, `Dispatch.cs`, `Environment.cs`, `Exceptions.cs`, `HostIntrinsics.cs`, `Interpreter.cs`, `Numbers.cs`, `Values.cs`. See the [project guide](../README.md) for usage, contracts and verification.
