# Plato SDF demo (TypeScript / Three.js)

Interactive browser for the forward-stdlib signed distance field catalog. Distance
evaluation comes from **TypeScript generated by `Plato.TypeScriptWriter`** over the
shipping stdlib tiers — not a hand-ported mirror of the formulas.

```bat
npm install
npm run gen:plato   # regenerates src/plato/plato.g.ts from stdlib/
npm run dev         # http://localhost:5174
npm run typecheck
```

`gen:plato` runs:

```bat
dotnet run --project ../../../src/Plato.CLI -c Release -- ^
  ../../../stdlib/foundation ../../../stdlib/geometry ../../../stdlib/graphics ^
  --out=./src/plato --typescript
```

## How it works

1. Plato source in `stdlib/geometry/implicit-sdf.*.plato` (and its foundation
   dependencies) is compiled by `Plato.CLI --typescript` into
   [`src/plato/plato.g.ts`](src/plato/plato.g.ts).
2. Scene modules build `FunctionSdf2D` / `FunctionSdf3D` values with
   `FunctionSdf*.Create` and call the generated members
   (`DistanceToSphere`, `SmoothUnionDistance`, `SdfTwistModifier3D.ApplyToDomain`, …).
3. Every distance value is produced by the generated library, on the CPU:
   - **2D** — `FunctionSdf2D.Eval` per texel into a canvas heatmap
     (white = zero level set), re-rasterized only when a parameter changes.
   - **3D** — worker threads evaluate `FunctionSdf3D.Eval` over a dense grid
     (32³ → 64³ → 96³, coarse first so the first image lands immediately);
     each bake is uploaded as a `Data3DTexture`.

4. The 3D viewer's fragment shader sphere-traces that baked texture with
   trilinear interpolation, and takes normals from central differences of the
   same samples. It is a display device, not a math library: it contains no SDF
   formulas, and reading a distance is always a texture fetch.

There is no parallel GLSL reimplementation of the SDF catalog in this demo — the
one-way flow is generated `Eval` → `Float32Array` → texture → pixels.

## Layout

```
src/
  plato/plato.g.ts     GENERATED — do not edit; npm run gen:plato
  scenes.ts            Scene catalog: build() → FunctionSdf2D|3D
  render/
    field2d.ts         2D field rasterizer
    bake.worker.ts     Samples FunctionSdf3D.Eval over a grid slab
    volume3d.ts        GPU raymarch of the baked field + OrbitControls
  main.ts              Sidebar + param UI
```

## Plato surface covered

| Generated API | Scenes |
|---|---|
| `Point2D.DistanceToCircle/Box/RoundedBox/Ring/Capsule/Triangle/Quad` | 2D primitives |
| `Point3D.DistanceToSphere/Box/RoundedBox/Torus/VerticalCapsule/CappedCylinder/CappedCone/Ellipsoid/Plane` | 3D primitives |
| `Number.UnionDistance/SubtractDistance/ExclusiveOrDistance/SmoothUnionDistance/ChamferUnionDistance/ExtrudedDistance` | CSG / lifts |
| `SdfShellModifier` / `SdfTwistModifier3D` | Modifiers |
| `Point3D.RevolvedPoint` | Revolution |
