feat(plato): C++ / CUDA backend with a compile-verification test project

Adds Plato.CppWriter, a TIR-only proof-of-concept backend for the C++ family, and
Plato.CppWriter.Tests, whose job is to prove the generated code compiles.

One emitter, two dialects. The generated code is byte-identical for C++ and CUDA;
only the preamble differs (vector types + the PLATO_FN qualifier), and a test
enforces that. Modelled on Plato.GlslWriter: free functions, aggregate structs,
native float2/float3/float4, intrinsics lowered onto <cmath> and the plato::
helpers the preamble supplies.

Three things C++ needs that GLSL did not:
- type-named conversion functions are renamed (Matrix4x4(Transform3D) -> ToMatrix4x4),
  because a function may not hide a type that later signatures have to name;
- conversions are explicit, including returns whose type differs from the declared
  return type, since C++ has no implicit user-defined conversion;
- a prune pass drops, to a fixpoint, any function calling a signature nothing
  emitted, so a skipped function cannot take its callers down with it.

Wired into Plato.CLI as --cpp / --cuda.

Gates: 8/8 tests green. demos/plato-src 66 emitted / 0 skipped; plato-src 461 / 1722.
Both compile clean under MSVC /std:c++17 /W3. The CUDA gate uses nvcc when the CUDA
Toolkit is installed and otherwise compiles the .cu as host C++ against a test-only
shim cuda_runtime.h; the mode is reported in the test output.

Neither project is registered in Ara3D.Studio.sln (that file lives in the studio repo).
