# Plato stdlib port ideas from ara3d-sdk

**Status:** brainstorm / unfiltered dump for review  
**Date:** 2026-07-31  
**Source of truth for Plato layout:** [submodules/Plato/stdlib/README.md](../submodules/Plato/stdlib/README.md)

## Purpose

Expansive list of **potential** Plato standard-library additions inspired by C# in `ara3d-sdk`. Ideas include classes, interfaces, libraries, domains, algorithms, and patterns — not 1:1 ports. **Filter ruthlessly later**; duplicates and overlaps with existing `stdlib/{foundation,geometry,graphics,future}` are expected.

Plato applications (from stdlib README): geometry, numerics, graphics, rendering; also image processing, scientific computing, math, physics, animation, engineering, games, VFX.

About **360** ideas below (unfiltered; expect duplicates across sections).

Each entry cites an originating C# file (relative link from `docs/`) and a short comment: **what**, **why**, **for whom**, **value**.

## How this was built

Parallel scouts walked `ara3d-sdk/src/*`, `deprecated/`, `wip/`, and selected examples/IO packages. Plato stems were spot-checked so some ideas call out likely gaps (e.g. remesh, Delaunay, AABB tree, OrientedBox3D).

Suggested stdlib homes while filtering:
- `foundation` — numerics, collections, units, hashing, tables
- `geometry` — meshes, curves, surfaces, SDF, spatial queries
- `graphics` — materials, scenes, cameras, images, animation
- `future` — engineering/BIM semantics, collision, optimization, particles
