# What is Plato

Plato is a programming language for immutable data and numerical algorithms.
A scientist gives lengths, angles, positions, and transforms distinct types, then
runs the same checked program in an interpreter or generates C# libraries.

## Who it is for

Scientists and engineers use Plato for typed geometry and numerics without managing
mutation. Developers embed Plato algorithms in .NET applications. Implementers and
agents use this reference as a readable contract, and as evidence of what the current
compiler does.
